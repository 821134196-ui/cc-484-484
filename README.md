# 农贸市场禽肉检疫票与分割批次系统

管理摊位、供应商代号、到货批次、检疫票编号、品类、到货重量、冷藏格位、
分割记录、销售托盘、余料、废弃物和市场抽查。**供应商与票据均为虚构数据。**

纯 Python 标准库实现（SQLite + http.server），零第三方依赖。

## 一条命令启动

```bash
python3 run.py                 # 重置数据库并载入样例，http://127.0.0.1:8080
python3 run.py --port 9000     # 换端口
python3 run.py --interval 15   # 扫描间隔（票据到期/冷藏超温），默认 30 秒
python3 run.py --no-reset      # 沿用现有数据库
```

启动即自动完成：建表 → 载入虚构样例 → 重量守恒审计 → 网页服务 → 进程内扫描线程。

样例覆盖：正常分割/销售/余料返工链、**票号重复**、票货不符、**称重差异拒收**、
**跨品类混放**、同品类共柜、**冷藏超温自动冻结**、标签脱落、抽查不合格联动冻结、
检疫票撤销冻结、**部分召回（含已售转追溯）**、废弃物占比异常，以及一张
约 70 秒后到期、由扫描任务自动冻结的票据。

## 八个页面

| 页面 | 功能 |
|---|---|
| 到货验票 | 摊主登记（票据缩略条+重量）；管理员核验有效期/票货相符/过磅±2%/测温/混放后放行入柜 |
| 批次库存 | 批次重量链路与守恒校验：到货 = 余量 + 在架/冻结托盘 + 已售 + 待处理余料 + 废弃 |
| 冷藏格位 | 格位占用、模拟温度探头读数、超温格位红色告警 |
| 分割称重 | 来源批次→分割单→托盘**流向图**；提交按批次余量扣减并生成托盘标签 |
| 托盘标签 | 标签图、销售、转余料、废弃、标签脱落/管理员补签、管理员解封 |
| 抽查冻结 | 市场抽查、撤销检疫票、冻结单范围（**冻结状态始终附文字原因**）、解封 |
| 召回清单 | 部分召回勾选托盘，清单**按摊位、托盘号排序**，销毁/结案 |
| 废弃物台账 | 分割损耗/变质/余料/召回销毁全部入台账，异常重量红色标记 |

右上角切换身份：**市场管理员**（验票、抽查、冻结/解封、召回、补签）或
**摊主 A01/A02/B01**（只能操作本摊位数据，跨摊访问被服务端拒绝）。

配色：市场白、冷藏蓝、检疫绿；所有票据/标签/现场图均为生成的 SVG 信息图，
**不使用任何肉类照片做装饰**。

## 核心规则

- **票号唯一**：`certs.cert_no UNIQUE` + `BEGIN IMMEDIATE` 事务，预查与唯一约束双保险。
- **重量守恒**：每次分割强制 `毛重 = 托盘合计 + 余料 + 废弃`；批次余量
  `到货 − 已分割毛重 − 批次废弃`，余料返工 `余料 = 新托盘 + 废弃`。
- **同一重量不能重复分割**：并发提交以批次余量为准，超出即拒（`insufficient_weight`）。
- **冻结传播**：检疫票撤销、抽查不合格沿批次链冻结 批次 + 未售托盘 + 待处理余料；
  部分召回只冻结清单内托盘，已售托盘登记追溯；超温格位冻结在柜批次链。
- **冻结可叠加**：托盘可同时受多张冻结单约束，解封单张时其余约束继续生效，
  全部解除才恢复在架。
- **角色隔离**：摊主仅能操作本摊位批次/托盘/余料；冻结和解封只有管理员能执行。

## 异常处理对照

| 异常 | 处理 |
|---|---|
| 票号重复 | 拒绝登记，`dup_cert` 事件 |
| 票货不符（品类/供应商） | 拒收，批次 `rejected` 并记录原因 |
| 称重差异 >±2% | 拒收（可勾选"差异登记放行"留痕） |
| 跨批次混放 | 跨品类共柜拒绝；同品类允许共柜 |
| 冷藏超温（-4~4℃外） | 禁止入柜；在柜链路由扫描任务自动冻结 |
| 标签脱落 | 摊主上报后禁售，管理员补签后恢复 |
| 部分召回 | 清单内未售冻结，已售转追溯，销毁入废弃物台账 |
| 废弃重量异常 | 单次废弃占毛重 >15%（单托盘>5kg/余料>8kg）红色预警 |

## 数据存放

- `data/market.db` —— SQLite 重量链路（WAL 模式，外键开启）
- `data/docs/` —— 虚构检疫票缩略条、托盘标签 SVG
- `data/photos/` —— 到货现场示意图 SVG

## 代码结构

```
run.py                  启动入口（重置/播种/扫描/HTTP）
poultry/
  config.py             阈值与路径（±2%、-4~4℃、15% 异常线等）
  database.py           SQLite schema、连接、事务、单号序列
  adapters.py           模拟电子秤 / 温度探头（带设备回执号，可预置异常）
  docs.py               票据/标签/照片 SVG 生成
  services.py           核心领域服务（验票、分割、冻结传播、召回、扫描、守恒审计）
  scanner.py            进程内定时扫描线程
  seed.py               虚构样例（重复票/混放/部分召回等）
  server.py             http.server JSON API + 静态文件
  web/static/           页面（index.html / app.css / app.js）
tests/                  unittest 用例
```
