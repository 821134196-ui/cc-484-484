# 农贸市场禽肉检疫票与分割批次系统（虚构演示）

管理摊位、供应商代号、到货批次、检疫票编号、品类、到货重量、冷藏柜、分割记录、
销售托盘、余料、废弃物与市场抽查。**所有供应商、检疫票、现场照片均为虚构数据**。

零第三方依赖，仅用 Python 3 标准库（`http.server` / `sqlite3` / `threading`）。

## 一条命令启动

```bash
python3 -m poultry_system.run --reset
# 打开 http://127.0.0.1:8000/
```

常用参数：`--host`、`--port 8000`、`--reset`（重建并重新载入样例）、`--interval 30`（扫描间隔秒）。

启动即载入样例：正常完整链、**重复票**、票货/称重差异、**跨批次混放**、
**部分召回**、检疫票到期、冷藏超温、标签脱落、废弃重量异常。

演示账号（右上角切换）：

| 账号 | 角色 | 权限 |
|---|---|---|
| `admin` | 市场管理员 | 抽查、检疫票撤销、召回、冻结/解封、异常处置 |
| `zhang` / `li` / `wang` | 摊主 | 登记到货、分割、销售、余料、废弃（**仅本摊位**） |

## 八个页面

到货验票 · 批次库存 · 冷藏格位 · 分割称重 · 托盘标签 · 抽查冻结 · 召回清单 · 废弃物台账

- 到货批次以**检疫票缩略条 + 重量**展示；
- 分割页绘制**来源批次 → 托盘 → 销售/余料 → 再托**流向图；
- 召回清单**按摊位、托盘号排序**；
- 任何冻结状态**始终附带文字原因**（红色说明条 + 留痕表）；
- 配色市场白 / 冷藏蓝 / 检疫绿，**不使用肉类照片作装饰**，票据与照片均为矢量示意图。

## 核心业务规则

- **到货验票**：票号唯一（DB UNIQUE 约束）、检疫票有效期、票货品类/重量相符、
  过磅称重差异；放行后才能入冷藏格位。
- **重量链路（整数克存储，杜绝浮点误差）**：分割从原批次扣减并生成托盘标签；
  销售、余料回收、余料再托继续沿用批次链。
  守恒式：`到货 = 未分割留存 + 批次废弃 + 分割损耗 + 销售 + 托盘废弃 + 余料废弃 + 托盘结存 + 余料结存`。
- **同一重量不可重复分割**；并发提交以批次余量为准——写操作 `BEGIN IMMEDIATE`
  取库级写锁，超量的并发分割整笔失败。
- **冻结传播**：检疫票撤销 / 抽查不合格 / 召回 → 相关**未售**托盘、余料、批次立即冻结，
  冻结即禁售；解封需根因消除（票有效、抽查已处置、召回撤回、超温已恢复）。
- **异常分别处理**：票号重复（拒收+异常单）、票货不符（拒收）、称重差异（暂挂待管理员确认）、
  跨批次混放（拒入）、冷藏超温（扫描冻结）、标签脱落（暂停销售待重贴）、
  部分召回（仅冻结清单托盘）、废弃重量异常（超阈值自动标记）。
- **角色边界**：摊主只能登记/操作本摊位，管理员负责冻结与解封。

## 后台任务与适配器

- 进程内守护线程（`tasks.ScanScheduler`）周期扫描**检疫票到期**与**冷藏超温**，
  可点页面右上角“立即扫描”手动触发，接口 `POST /api/scan`。
- 模拟适配器（`adapters.py`）提供**称重回执**（可注入偏差制造称重差异）与
  **温度回执**，回执落库 `adapter_receipts`。

## 数据存放

- SQLite：`market_data/poultry.db`（重量链路唯一事实来源，WAL 模式）
- 虚构票据：`market_data/tickets/*.svg`；现场照片：`market_data/photos/*.svg`
  （经 `/data/...` 提供，含目录穿越防护）

## 测试

```bash
python3 -m unittest poultry_system.tests.test_system -v
```

覆盖：**票号唯一、重量守恒、冻结传播、并发分割（8 线程竞争不超卖）、摊位隔离**，
以及八类异常分支（28 个用例）。

## 目录结构

```
poultry_system/
  db.py        SQLite schema + 事务(BEGIN IMMEDIATE)
  service.py   领域服务：验票/入柜/分割/托盘/余料/废弃/抽查/撤销/召回/冻结/守恒核算
  adapters.py  模拟称重、温度适配器（回执）
  tasks.py     进程内到期/超温扫描线程
  server.py    标准库 HTTP：JSON API + 静态前端 + /data 文件
  seed.py      虚构主数据、SVG 票据/照片、异常样例
  run.py       一条命令启动
  web/         index.html / app.js / styles.css
  tests/       unittest 套件
```
